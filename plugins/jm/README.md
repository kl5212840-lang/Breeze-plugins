# 禁漫天堂+（Breeze 插件）

这是基于 [mumushu0501-boop/Breeze-plugin-JmComic-change](https://github.com/mumushu0501-boop/Breeze-plugin-JmComic-change) 的独立维护分支。感谢原作者提供禁漫账号、收藏、评论及多线路能力。本分支不是禁漫天堂官方网站或原作者发布的客户端。

## 使用

在配套的 [Breeze fork](https://github.com/kl5212840-lang/Breeze/releases) 插件商城安装“禁漫天堂+”；如果已安装原版 `禁漫天堂(mumushu0501-boop)`，本分支沿用同一插件 ID，更新时会替换该插件并保留按此 ID 保存的本地记录和设置。应用界面的新版“我的”、分类卡片和首页封面排版需要 Breeze 3.0.37 或更新版本。

插件与应用分别更新：更新插件不等于更新 IPA，更新 IPA 也不会自动替换已安装的插件。发布包可在本仓库 [Releases](https://github.com/kl5212840-lang/Breeze-plugin-JmComic-change/releases) 获取。

## 体验重点

- 推荐、分类、最新、排行榜和“我的”构成完整浏览路径。
- “我的”集中展示账号、签到、站内/追漫消息、云端收藏及 Breeze 本地阅读记录；收藏和记录有封面预览。
- 漫画详情保留阅读、追更、本地/云端收藏、评论、目录与下载；长标签默认折叠。
- 图片和接口线路可测速、手选与失败回退。网络失败时保留重试入口。
- 不收录官网广告、博彩或无关活动入口。官网部分活动/任务没有已验证的插件接口，因此没有伪造按钮。

云端内容和登录由禁漫服务提供，可能随站点或线路变化而暂时不可用。本插件不会把账号密码写入调试日志；账号设置仍按 Breeze 原有同步范围处理，建议仅使用自己信任的同步服务。

## 开发

运行 `pnpm install --frozen-lockfile` 和 `pnpm build`；构建产物在 `dist/`。源码与原项目的历史保留在本 fork 中，修改重点见 `src/get-info.ts`、`src/index.ts` 和 `src/client.ts`。

离线回归运行 `pnpm test`，使用内存存储和本地 Axios 适配器，不会登录账号或写入真实收藏。覆盖空缓存、清理会话与在途响应、收藏失败状态，以及登录和签到的有限重试。自动登录与签到各最多尝试三次；明确凭据错误立即停止，临时网络错误延迟后重试。清理会话保留设备标识与线路设置。
