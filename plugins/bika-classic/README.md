# 哔咔漫画（本地候选）

以用户选定的 PicACG iOS 2.5.85 安装包和截图为参考的独立社区适配，与“哔咔漫画+”并存。不是原发布者发行，完整原App功能仍有缺口。

- 独立 UUID：`97b8ebb1-9f1f-423c-9847-acd7b0ccd31f`，当前候选0.1.2。
- 首页组合分类、热词与真实排行榜/最近更新/随机入口；不重复分类tab，不额外请求漫画预览。
- 外观只提供“原版粉色 / 跟随全局”，默认只读原版粉色；沿同UUID插件设置保存，不写全局样式。
- 复用成熟详情、阅读、搜索、排行榜、登录、资料、头像、签到、评论、站点收藏与视频适配。每份CJS含自己的代码，不依赖另一份已安装插件。
- 本机收藏、历史、下载与账号各自独立；不声明旧源别名，不读取或复制其他插件资料。站点收藏由实际登录账号决定。
- 启动只恢复本插件线路，不自动登录/签到。首页失败就地重试，不后台循环；成功内容只在同账号、线路及屏蔽条件内保留。
- 游戏、原生注册/找回尚无完整可证合同；四标签目标未达。一次性主动导入未实现。没有用假入口或未知网页补功能。

复用相邻 `../bika` 已有依赖，不新增依赖副本：

```sh
node build/build.mjs
node --experimental-transform-types --test tests/*.test.cjs
node ../bika/node_modules/typescript/bin/tsc --project tsconfig.json --noEmit
```

构建器仅在本次编译将共享核心的info/identity替换为本插件，检查成品没有旧UUID。测试读取实际CJS和相邻旧Bika成品验证两源并存；没有真实账号、网络或用户存储。

本地文件为 `dist/breeze-plugin-bika-classic.bundle.cjs` 与 `manifest.json`。updateUrl为空，没有发布/上传。实际候选范围、验证入口、证据和剩余项见 [0.1.2说明](docs/candidate_0.1.2_2026-11-03.md)。
