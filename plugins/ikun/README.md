# iKun 资源 Breeze 插件

通过 iKun 公开采集接口提供影视目录、分类、搜索、作品详情和分集数据。需要支持 `openVideoLibrary` 协议的配套 Breeze 宿主。

收藏、文件夹、快速查找、两种视图与 Breeze 云同步由宿主管理，不是 iKun 站点账号功能。当前服务端筛选仅启用有证据的分类与年份，不伪造地区、语言、热榜或点赞接口。

运行文件为 `ikun-native.cjs`。执行 `npm test` 检查解析及网络边界；真实接口、iPhone 播放与云同步的验收单独记录，测试通过不代替实际使用验证。插件发布与更新统一由本仓库管理，安装方式见根目录说明。
